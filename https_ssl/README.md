# https_ssl

Exercises on DNS subdomains and SSL termination with HAProxy.

| File | Description |
| ---- | ----------- |
| 0-world_wide_web | Displays information about a domain's subdomains |
| 1-haproxy_ssl_termination | HAProxy config accepting HTTPS on port 443 |
| 2-redirect_http_to_https | HAProxy config redirecting HTTP to HTTPS with a 301 |
